# 图片批量转换（本地 · 零联网）

把任意图片或文件夹里的所有图片，统一转换为**相同比例、相同大小**的图片，适合在 1.5×1.5 cm 小屏幕上清晰显示。

- 单文件交付：**双击 `index.html` 即可使用**，无需安装任何东西（0 环境依赖）
- 支持 Windows / Linux / Android（Chrome、Edge、Firefox 等现代浏览器）
- 纯本地运行，**不发起任何网络请求**，图片不会离开你的设备

## 使用方法

1. 用任意现代浏览器打开 `index.html`
2. 拖入图片/文件夹，或点击「选择图片 / 选择文件夹」（支持整文件夹含子文件夹）
3. 在「输出设置」中调整：
   - **目标大小**（默认 100 KB，支持 1 KB – 2 MB）
   - **输出尺寸**（物理，默认 1.5 × 1.5 cm）——所有输出图片的物理长宽严格一致
   - **输出格式**：保持原格式 / JPEG / JPG / PNG
   - **容差**（默认 ±2%）
   - 低清晰度增强开关（默认开）
4. 点击「开始转换」，完成后可「下载 ZIP」打包导出（文件名与文件夹结构不变）、「下载全部」逐张直接下载（跳过失败项），也可单张下载

## 输出规则

- **物理尺寸统一**：所有输出图片的长宽严格一致（默认 1.5 × 1.5 cm），只调整像素，不改变物理尺寸
- **像素精度由目标大小实时演算**：系统为每张图独立演算恰好能承载目标大小的像素密度（DPI）——内容简单不足以承载时自动提高 DPI（上限随目标增长：50KB 目标约 470px，2MB 目标约 1500px，硬顶 2048px，不过度放大），内容过剩时保持适当 DPI 并高质量压缩；演算结果写入文件元数据（JPEG JFIF / PNG pHYs），在任意查看器中均显示为设定的物理尺寸
- **统一大小**（硬约束：结果 ≤ 目标大小 ×（1+容差））：
  - **JPEG/JPG**：精确命中目标大小（±容差，默认 ±2%）；极简单内容达到 DPI 上限仍不达标时输出最大可达大小并标注原因
  - **PNG**：全程无损——二分像素搜索「直通 ≤ 上限的最大像素」，无损命中目标区间，无任何量化损失；内容限制时输出最大可达
- **小目标（≤8KB）**：大小容差自动放宽至 ±12%；JPEG 质量下限随目标缩小（1KB ≈ q30，≥21KB 回到 q90）；PNG 保持无损尽力而为，内容受限时输出最大可达（≤ 容差上限）；自动轻度去噪提升压缩率，输出附锐化
- **低清增强**：源图小于目标时自动高质量上采样 + 锐化 + 自动对比度
- **裁剪**：原图过宽 → 居中裁左右；原图过高 → 按 **3:7 裁上下**（上方 30%、下方 70%）
- **文件名不变**：仅扩展名随输出格式变化；ZIP 中保留文件夹相对路径

## 平台说明

- **Windows / Linux**：任意浏览器双击打开 `index.html`
- **Android**：把 `index.html` 复制到手机，用 Chrome / Edge 打开（文件管理器 → 选择浏览器打开）；「选择文件夹」在 Android Chrome 同样可用
- 设置（目标大小、比例、格式等）会自动记忆，下次打开仍有效

## 常见问题

- **HEIC 等格式无法解码**：浏览器不支持，请先用系统工具转换为 JPEG/PNG
- **转换后的图片小于目标大小**：内容极简单时最高质量也达不到目标，属正常现象
- **1KB 级 PNG 输出达不到目标大小**：PNG 为无损格式，仅极简单内容（纯色/渐变）能压到 1KB；照片类输出内容受限的最大可达值（≤ 容差上限），属正常现象
- **隐私**：本工具无网络功能，可放心处理私人照片；处理全程在本机内存完成

## 开发

```bash
node --test tests/logic.test.js   # 单元测试（逻辑层）
node build.js                     # 由 src/ 重新打包 index.html
node tools/gen-fixtures.js        # 重新生成测试图片
node tools/gen-e2e.js && node tools/e2e-run.js   # 无头浏览器端到端测试
```

源文件：`src/logic.js`（纯逻辑引擎）、`src/app.js`（UI/管线）、`src/style.css`、`src/index.template.html`。**零第三方依赖**，全部使用浏览器原生能力（canvas / createImageBitmap / CompressionStream）。
